---

## Training Breakdown

### Database Programming Refresher

- **Day 1: DBMS Fundamentals & RDBMS Basics**
  - Content: Types of DBMS (Relational vs Non-Relational), MS SQL Server & T-SQL introduction, RDBMS concepts (DDL/DML).
  - Practice: Set up MS SQL Server environment, begin ER Diagram for Health Clinic App.

- **Day 2: ER Diagram, Indexing & Normalization**
  - Content: ER Diagram design principles (entities, relationships, cardinality), Table Indexing performance, Normalization Forms (1NF, 2NF, 3NF, BCNF).
  - Practice: Finalize ER Diagram for Health Clinic App.

- **Day 3: Joins, Stored Procedures & Triggers**
  - Content: SQL Joins (Inner, Left, Right, Full Outer), Stored Procedures creation/usage, Triggers.
  - Practice: Write joins, stored procedures, and triggers for Health Clinic App.

- **Day 4: ADO.NET & Health Clinic App Completion**
  - Content: Connecting .NET application to MS SQL Server using ADO.NET, CRUD operations.
  - Practice: Finalize console-based Health Clinic App (Implemented CRUD Operation on All Table(Doctor , Patient , Appointment)).
